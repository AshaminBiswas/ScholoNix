# Accessibility Skill

## Requirements
- Target WCAG 2.2 AA unless the product specifies a stronger standard.
- Use semantic landmarks, headings, buttons, links, labels, and table structures.
- Ensure complete keyboard operation, logical focus order, visible focus, and focus restoration in dialogs.
- Associate validation messages with fields and announce dynamic errors/statuses appropriately.
- Provide text alternatives for meaningful images and accessible names for icon-only controls.
- Never rely only on color, hover, or drag interaction.
- Respect reduced motion, zoom, and text resizing.

## Validation
Run automated accessibility checks, then manually test keyboard-only flows and screen-reader-critical journeys. Record known exceptions and remediation.
